Correcting or rearranging existing entries

All content lives in one file, data/compendium.json. To fix a typo, mark a problem as tight, merge duplicate problems or move a tag to a different group, edit that file directly on GitHub:

Edit data/compendium.json on GitHub

  1. Use the pencil icon if the file opens in view mode. Press Ctrl+F to find the problem.
  2. Make the change, keeping the quotes and commas as they are. In this file each backslash is written twice: \\(k\\).
  3. Click Commit changes. The site updates within a couple of minutes.

Useful fields on a problem: "tight": true marks the bounds as matching. "short" is the abbreviation. "tags" drives the filters. If you break the file by accident, GitHub keeps every earlier version under History.
